# **App Name**: DevConnect Pro

## Core Features:

- Data API Integration: Connects to a backend API (e.g., Django REST Framework or Next.js API Routes) to dynamically fetch and display portfolio content, ensuring content can be easily updated without direct code changes.
- Responsive Sectioned Layouts: Provides dedicated, responsive layouts for Home, About, Skills, Projects, Experience, and Contact sections, optimized to deliver a seamless user experience across all devices and screen sizes.
- Interactive Project Portfolio: Showcase real-world projects with detailed descriptions, relevant media, and functionality for basic filtering or pagination to help visitors explore the developer's work efficiently.
- Skills & Experience Presentation: Organized and clear presentation of developer skills, categorized by domains like Frontend, Backend, DevOps, and Tools, alongside a chronological display of professional work experience.
- Direct Contact Form: An interactive contact form allowing visitors to send messages directly, integrated with a secure submission handler to facilitate communication.
- AI Content Assistant Tool: An integrated AI tool that leverages natural language processing to assist in refining or generating concise and impactful project descriptions for the portfolio, demonstrating AI skills.

## Style Guidelines:

- Primary color: A professional, muted blue-gray (#475769) for main headings and interactive elements, conveying stability and professionalism.
- Background color: An extremely light, subtle blue-gray (#F6F7F9) as the base, providing an airy and modern foundation for content with a light gradient feel.
- Accent color: A warm, desaturated gold (#E6B44F) for call-to-action elements, highlights, and subtle contrasting details, adding an inviting touch without being flashy.
- Headline and body text font: 'Inter' (sans-serif) for its modern, neutral, and highly readable aesthetic, ensuring clarity across all content types.
- Utilize a consistent set of minimal, clean line icons. These simple vector icons will complement the modern and uncluttered UI, focusing on clarity and functionality.
- Content presented within 'white cards' with subtle, soft shadows for depth, creating visual separation. The overall design emphasizes ample whitespace and consistent spacing between components for a calm and focused user experience. Responsive design is a core principle, ensuring adaptability to all screen sizes.
- Subtle and purposeful micro-interactions and transitions for hover states on interactive elements, navigation links, and seamless section changes, providing smooth user feedback without distracting from the content.
